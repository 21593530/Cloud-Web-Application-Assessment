# Assessment 1 Notes

## Project scope
PhonoTrail Studio is a frontend-only Next.js web application for Assessment 1: Frontend Design and Usability.

## Requirements captured from the assessment brief
- Build a teacher-facing toolkit for phoneme-based classroom activities.
- Focus on frontend design, usability, responsive layout, and accessibility.
- Implement two activities: Wordle and Word Search.
- Use phoneme-based content rather than standard spelling.
- Provide interactive previewing inside the app.
- Generate downloadable standalone HTML files for each activity.
- Keep the app frontend-only: no backend or database.

## Required pages
The app must include exactly these five navigable pages:
1. Home
2. About
3. Wordle
4. Word Search
5. Settings

## Functional expectations
- Teachers should be able to create, preview, and export each activity.
- The exported HTML should be a single playable file with embedded CSS and JavaScript.
- Wordle should use one phoneme-based word and provide guess feedback.
- Word Search should use a small phoneme-based word list and generate a playable puzzle.
- Accessibility support should include phoneme hints through mouse-over titles or equivalent affordances.
- Light/dark theme changes should persist using cookies.

## Design expectations
- Professional and highly readable interface.
- Light mode: crisp white/ice-blue backgrounds with deep navy text.
- Dark mode: deep navy backgrounds with off-white text.
- Gold should be used only for accents and active states.

## Submission expectations
- GitHub repository link required.
- Project code zip required.
- Video submission required, including face, voice, and student ID.
- AI acknowledgement required if AI tools were used.
- Minimum five academic or industry sources in APA 7th style if referenced.

# References and AI acknowledgement

## AI acknowledgement

Generative AI tools were used across the staged development of PhonoTrail Studio:

- GitHub Copilot and Claude Sonnet 4.5 assisted during Assessment 2 with Prisma/SQLite persistence, Zod validation, API routes, builder CRUD integration, keyboard accessibility, Docker configuration, and documentation.
- OpenAI Codex assisted during Assessment 3 with repository and brief analysis, the metric/data contract, `UsageEvent` persistence, validated instrumentation, dashboard aggregation and presentation, alert resilience, Playwright isolation, JMeter and Lighthouse procedures, Docker regression tooling, evidence interpretation, and documentation.

AI outputs were not accepted as evidence on their own. The student reviewed the proposed code and writing, retained control of architectural and scope decisions, and evaluated outputs against the assessment brief and rubric. Claims were checked using committed migrations, disposable databases and volumes, validation scripts, TypeScript, production builds, Playwright, JMeter, Lighthouse, HTTP responses, database hashes, and browser-based workflows. Assessment 1/2 behavior was preserved unless explicitly approved, and limitations or failed checks were recorded rather than hidden.

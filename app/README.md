# PhonoTrail Studio

PhonoTrail Studio is a frontend-only Next.js experience built for Assessment 1. It presents a polished teacher-facing toolkit for phoneme-based classroom activities, with two interactive learning tools: a Word Search activity and a Wordle-style activity.

## Included pages

- Home — overview of the teaching toolkit
- About — assessment context and project rationale
- Word Search — interactive phoneme-based puzzle builder with exportable HTML
- Wordle — classroom-ready phoneme Wordle with hints, feedback, and exportable HTML
- Settings — light/dark theme selection with persistent preference

## How to run

```bash
npm install
npm run dev
```

Open http://localhost:3000 to view the site.

## Build verification

```bash
npm run build
```

The app is intentionally frontend-only and designed to feel like a practical educational product rather than a starter template.
